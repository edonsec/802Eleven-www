What it does

802Eleven is a WiFi toolkit designed for network analysis and security oriented testing. When used with a standalone device, it provides a streamlined UI to observe, analyse, defend and simulate attacks against authorised networks.

OBSERVE

Passive monitoring and discovery

Proximity radar

Observe your networks and their associated stations in an interactive radar, showing relative positions of devices based on approximate signal strength.

Cloaked‑network reveal

Unmask hidden SSIDs broadcasting in your proximity.

Targeted Channel Selection

Apply granular control over captured channels and frame types.

5GHz dual‑band support

Capture across both 2.4 GHz and 5 GHz with independent channel selection. (ESP32‑C5 boards)

GPS‑tagged discovery

Tag discovered SSIDs with GPS coordinates.(requires GPS module + SD card on Cardputer Adv)

DEFEND

Passive threat detection

Deauth sentinel

Detects nearby deauthentication attacks, be alerted to their presence.

Karma sentinel

Flags access points that respond indiscriminately to client probe requests, a hallmark of KARMA attacks.

Rogue Device sentinel

Identify nearby suspicious devices and rogue devices.

SIMULATE

Test active methodology against your own infrastructure

Frame crafting

Craft and send raw 802.11 frames, including modification for most headers. Detect flaws within your device's wifi frame parsing by tweaking Information Element (IE) lengths.

Local AP

Deploy a custom access point and capture client DNS requests. Gain the insight to how your device behaves on a network.

CONFIGURE

Interfaces, filters, and preferences

Web dashboard

Browser‑based interface for monitoring and controlling the device over the board's own WiFi AP.

Frame filtering

Target only the channels and frame types you want to analyse.

Serial interface

Control the device over USB/UART, freeing the radio and dedicating it to wifi scanning. Supported devices only.

Themes

Choose from a variety of colour profiles.

Supported hardware

Several ESP32 boards are currently supported, each with its own unique features and capabilities.

Primary boards

ESP32‑S3 DevKitC‑1

Primary build. Standalone or paired with a 2nd board as a Scout.

Seeed XIAO ESP32‑C5

Thumb‑sized dual‑band (2.4/5 GHz) primary/base build. Also runs as a Scout. Please see below.

M5Stack Cardputer Adv

Fully featured build with Cardputer centric UI and support for Sentinel and frame crafting. Wire up a GPS module and flash the -gps image to add GPS‑tagged GPS logging.

CYD (Cheap Yellow Display)

Touchscreen centric UI, 2.4Ghz support only and no GPS.

CYD‑C5

Cheap Yellow Display on ESP32‑C5, same as the standard build but supports dual‑band (2.4/5 GHz) and takes advantage of the improved hardware with an animated radial menu.

T‑Dongle‑C5

Pocket dongle form factor, dual‑band (2.4/5 GHz), tiny screen. Standalone Sentinel and Web application.

Scout companions optional 2nd board — continuous monitor‑mode capture, streamed to a paired primary

ESP32‑S3 DevKitC‑1

Scout build which pairs with the primary S3 over UART. No Web UI of its own.

Seeed XIAO ESP32‑C5

Scout build, dual‑band (2.4/5 GHz) hop — same board as the Primary image above, UART remapped to the XIAO's D6/D7 pins.
Every currently supported device above also has a browser sim — see the Sims section.
